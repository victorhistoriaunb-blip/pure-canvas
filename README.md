# Insightful Finance

Crie uma aplicação web moderna, extremamente visual, elegante e responsiva, inspirada no estilo do Power BI, utilizando uma interface clean, minimalista e tecnológica.

## Objetivo

O sistema será um Dashboard Financeiro Pessoal integrado ao Google Sheets.

Toda a base de dados será armazenada em uma ou mais planilhas do Google Sheets.

O dashboard deverá atualizar automaticamente sempre que houver alteração na planilha, sem necessidade de editar código.

O Google Sheets será o banco de dados principal.

---

# Login

Crie uma tela inicial de Login.

O objetivo não é criar múltiplos usuários.

Será apenas uma camada de proteção para acessar os dados financeiros.

A tela deve possuir:

* Logo no centro

* Campo Usuário

* Campo Senha

* Botão Entrar

* Fundo moderno com elementos tecnológicos discretos

* Pequena animação de entrada

Após autenticar, abrir o Dashboard.

Quero abrir o dashboard e entender imediatamente para onde meu dinheiro está indo.

A navegação deve ser intuitiva.

Os gráficos devem ser bonitos, modernos e úteis.

O resultado final deve parecer um produto SaaS premium, com qualidade visual comparável a ferramentas profissionais de Business Intelligence, porém voltado para controle financeiro pessoal, simples, intuitivo e agradável de utilizar.
